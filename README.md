# Culinometry 
## A Precision Recipe Creator
> Culinometry is a mobile Android application intended for Android 8 and up. 
> 
> The purpose of Culinometry is to be a recipe app that provides centralized digital storage of a users recipes. 
> 
> Culinometry is not intended to supply recipes but to be a place in which users can create and store their own recipes that they find.

## Who is Culinometry meant for?
> The intended target audience for Culinometry is home cooks, enthusiasts, and professional chefs alike. Really anyone can make use of this app for cooking.

## What is the current progress?
> Culinometry is still in its pre-release phase and still has a lot of baseline functionality in the works. The current release is very barebones and is more of a prototype than a final release.
